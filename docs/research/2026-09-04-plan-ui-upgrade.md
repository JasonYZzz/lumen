# 普通模式与 Plan Mode 交互升级

> 历史实施记录：本文所述“保留页头计划入口”和完成后的胶囊已被后续用户反馈修订。当前行为与预览能力见 [计划与产物展示复审](2026-09-04-plan-document-review.md)，不要将下文作为现行 UI 规范。

本轮以 `docs/chatgpt_codex_plan_ui_prototype.html` 的 HTML/CSS 和交互脚本为参考，修改现有 Web Adapter。原型中的模拟计时、来源数量、文件数量、假消息与场景切换不作为生产状态。

## 已实现

- 普通模式：输入框上方显示当前轮次的步骤摘要；向上打开宽 390px、受视口约束的非模态清单，长列表独立滚动。复用已有步骤、依赖、说明、验收条件及五种状态。Esc、关闭、外部点击和焦点移出关闭；中文输入法 Escape 不误关闭。
- Plan Mode：探索阶段显示规划状态；待审方案在正文展开阅读，底部卡片提供确认或修改。修改时聚焦反馈框，失败保留内容，可返回确认。模式选择器以浅蓝色标识先规划模式。
- 状态安全：完成数只代表步骤；当前轮没有计划时不显示旧轮计划。审核携带现有 revision；同步请求引用阻止重复点击，导航使旧响应失效，避免把运行订阅或错误接到其他任务。审核过程中普通发送保留草稿，不竞争启动另一运行。

保留页头计划检查视图、历史计划事件、Host 审核、工具审批与恢复路径；没有更改 Python、Session schema 或模型提示词。
