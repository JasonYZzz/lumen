# Web 任务进度、侧栏与模型菜单

日期：2026-09-03。本文记录本轮设计依据与验证，不替代源码和 Accepted 决策。

## 观察

参考用户提供的三张截图，并在当前 Chrome 中观察 ChatGPT 的模型搜索与侧栏展开、收起状态。1920×832 下，参考侧栏展开约 260px，收起保留 52px 图标栏；搜索与模型列表在同一个轻边框浮层内，与输入区同宽。参考中的其他产品入口不代表 Lumen 具备对应能力，因此不复制资料库、项目、已安排、账号等入口。

用户截图中的 Lumen 任务卡片在处理结束后仍展开，占据最终答案前的大段高度。目标、版本、进度横线、数字计数和逐行状态重复表达同一进度。模型搜索旧样式则嵌套边框并重复当前模型信息，增加了选择动作的视觉负担。

## 实现

- 计划作为活动层的一部分，同轮仅保留最新快照的投影；默认是一行状态、计数和展开箭头。成功后随处理过程收起，点击仍能查看说明、依赖和验收条件。顶栏和 `/tasks` 保留完整最新计划。
- 桌面侧栏采用 260px 列表和 52px 窄栏，收起偏好持久化。窄栏仅保留展开、新任务、任务搜索；移动端使用遮罩、焦点约束和焦点返回，开关不污染桌面偏好。
- 模型菜单对齐输入区，搜索无嵌套边线；图标、真实配置名称、选择标记形成单行。保留异步切换反馈、错误和重试，兼容输入法。
- 输入框获得焦点时不加粗边线。模型菜单聚焦和关闭后的焦点恢复使用 `preventScroll`：修复原先将 `overflow: hidden` 的对话外层滚动、导致整个输入区上移的问题。

## 删除与保留的证据

原计划卡片进度条、版本说明及相关 CSS 被同一个 PlanPanel 的轻量投影完全替代；相应 DOM 已无生产调用。旧模型菜单中的重复描述由选中标记替代。以上只删除重复展示，不删除计划数据或功能。

Session journal、Runtime、Host、Plan review revision、审批与 Sandbox 没有变化。失败运行仍展开过程并显示错误；待确认方案仍提供完整计划、修改意见与确认执行。原有运行时、检查点、运行记录、设置和归档入口保留。

## 验证

Web 的 101 项测试、TypeScript 检查和 Next 生产构建通过。生产静态包在独立 localhost:8769 上通过真实 Web → API → Host 链路验收，使用临时 Session 和两个模拟模型，没有向外部模型发送验收内容，未重启用户 8765 服务。

桌面模型菜单和输入区均宽 800px，开关前后输入区 y=723，外层 scrollTop=0；搜索 outline-style=none。手机 390×844 下浮层 x=12、width=366，body.scrollWidth=390。已验证真实筛选和模型切换、侧栏搜索/收起/展开、手机 Esc 焦点返回、方案确认及失败状态。动态计划与结束折叠由 DOM 回归覆盖。

截图与逐项验收见根目录 `design-qa.md`，资源在 `outputs/chrome-ux-2026-09-03/`。尺寸与信息层次对齐参考，同时保留 Lumen 品牌和实际能力；不声称与 ChatGPT 所有页面像素一致。
