# Web 对话与执行过程体验升级

本次范围经用户确认：保留 Lumen 品牌、导航与功能，优先对齐对话与执行过程。
采用 impeccable 的 Operate 模式及 distill 原则，改动只涉及 Web 展示投影。

## 参考与证据边界

已直接检查本地 WebUI 的真实运行任务及源码、交互测试。
ChatGPT 浏览器接口因 request-header policy 加载失败，未取得可靠的当前登录态
思考面板与工具调用捕获。本报告不主张逐像素复刻或验证了当前 ChatGPT 全部状态。

[ChatGPT Work 与 Codex 官方说明](https://help.openai.com/en/articles/20001275/)
描述了查看进度、补充信息、调整方向及审批重要操作的交互能力。
[ChatGPT agent 官方说明](https://help.openai.com/en/articles/11752874-chatgpt-agent)
是工具执行、用户控制与审批的参考。具体折叠默认值、字号与布局属于本次 Lumen
设计选择，不作为 ChatGPT 当前实现事实。

## 对比与落地

| 维度 | Lumen 原有体验 | 本次调整 |
| --- | --- | --- |
| 当前进展 | 运行中铺开完整历史，长任务占用阅读空间 | 默认收起历史；显示当前状态、最新进展短预览、正在执行的工具 |
| 思考层级 | 与后台事件混在末尾的原始详情 | 按发生顺序放回过程，每段思考独立展开，保留 Markdown |
| 工具详情 | 可查看输入输出，运行中也显示空输出 | 运行中说明结果尚未返回；展开后长路径换行，保持可读结果与原始记录切换 |
| 历史回顾 | 调用数和失败次数仅在悬停提示 | 摘要直接显示工具调用数及失败记录数 |
| 长过程 | 主层随整页滚动，原始详情有界 | 完整过程与当前并发工具都有局部滚动范围 |
| 用户控制 | 手动折叠状态保留，审批独立可操作 | 保留契约；审批与终止异常仍自动展开，状态可被屏幕阅读器播报 |
| 最终回答 | 与执行说明可能争夺注意力 | 收起时不再重复显示此前进展，保留回答、来源、文档与计划入口 |

## 保留的契约

- 不生成或改写推理内容，不改变 journal、Provider 消息、工具参数、审批与完成语义。
- 只合并声明可分组的连续成功调用，失败与正在执行的调用仍逐条保留。
- 历史失败次数是审计提示，不将已恢复的错误解释为待处理审批。
- 耗时仍采用 Runtime 保存的整轮实际时间，不伪装为纯模型思考时间。
- 来源分类、安全链接、文档预览、澄清、防重复提交与原始记录入口保留。
- 根 PRODUCT.md / DESIGN.md 描述 Architecture Atlas，不能用其配色或布局覆盖 WebUI。
  本次保留 WebUI 现有中性表面、Geist 字体、Lumen 标识及全局导航。

## 验证目标

交互回归覆盖默认收起、手动打开跨完成状态保留、思考与工具顺序、并发执行预览、
审批独立入口、失败与中断、等待用户、预览焦点恢复、真实耗时与原始记录。
完整 Web 测试、TypeScript 检查与静态构建作为交付门禁；真实 Provider 执行不由这些检查证明。

实际结果：完整 Web 测试 182 项通过，补充预览交互后单独复跑的对话组件 17 项全部通过；
`pnpm --dir src/web typecheck`、`pnpm --dir src/web build`、`git diff --check` 通过。
impeccable detector 对修改的 UI 组件返回空发现列表。
桌面真实任务的收起与展开状态已通过浏览器截图检查。
移动端模拟未取得有效截图：浏览器接口 request-header policy 加载失败，后续原生
Chrome 窗口也返回 Screenshot unavailable；移动端视觉验收仍未完成。
仅用于验证的 3001 端口开发服务已停止。

## 后续调整：连续过程与完成收起

用户提供 ChatGPT 过程截图并明确要求执行信息直接输出、完成后收起及活动步骤文字流光。
本节取代上文关于默认收起、思考二次折叠、成功工具分组及手动打开跨完成保留的方案。

运行期间默认展开，进展与思考正文直接按序阅读，工具为无框单行；不折叠长进展或成功调用组。
活动过程使用页面滚动，完成后回看使用有界阅读区。成功结束切换阶段时统一收起，
运行期间的手动展开不阻止这次收起；结束后仍可手动回看，失败/停止和独立审批保持可用。
当前思考标签、所有并发执行工具及当前运行状态使用同一低对比变化的文字扫光，
停止、完成和审批等待移除步骤流光；减少动态效果及强制颜色模式回退静态文字。
实际推理内容只来自已有公开事件，不生成隐藏推理或猜测进度。

回归覆盖连续顺序、长文字、并发工具、阶段切换、回看、审批暂停流光及焦点返回。
完整 Web 测试 193 项、类型检查及生产静态构建通过；审批预览的流光暂停补充检查后，
对话组件 19 项回归再次通过。Chrome 桌面与 390px 模拟移动视口已验证运行和完成。
本地临时验收页已移除，未调用真实 Provider。真实流式 Provider 与移动设备性能不由这些检查证明。
设计检测的文字渐变提示对应用户明确要求的活动步骤流光，仅作用于活动状态；
既有侧栏 width transition 提示不属于本轮变更，保持原行为。
