## 必须同时通过的视觉门槛

参照 public/mascot/fox-poster.png 和现有 idle/react 视频，以同一取景、大小、背景比较真实 WebGL 渲染。

- 角色轮廓、头身比例、耳形、口鼻和眼神一致，不能用抽象几何体近似代替。
- 九条尾巴的数量、蓬松体积、扇形分布和粉蓝紫渐变与原图一致。
- 白色毛发具备柔软层次、边缘细毛和自然光照；光滑塑料或陶瓷质感判定失败。
- 168px 实际展示尺寸与 2× 放大均通过；正面、侧面、转动及 idle/react 全程无明显穿插或变形。
- 在产品实际浏览器渲染中通过，而不是只凭 Blender 离线渲染或生成图片；用户确认达到参考图效果后才允许变更启用门禁。
- 性能、静态偏好、离屏暂停、失败回退继续满足既有约束；M4 尚未执行，不能宣称设备验收完成。

任何一项不满足，继续视频，不开放切换入口，不随站点发布实验 GLB。
不虚构“相似度百分比”；以参考图并排检查和用户验收为准。

Imagegen 可辅助制作多视图参考和纹理草案，但生成图片不等于可用的三维几何、毛发或动画，
不得用图片上的质量替代真实模型验收。
